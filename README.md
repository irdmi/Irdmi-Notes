# Irdmi Notes

> Пиксельный редактор заметок в виде **библиотеки**.

**Irdmi Notes** — это статичное веб-приложение, которое превращает рутинное ведение заметок в процесс расстановки книг на полках.

## Возможности
-  **Зал библиотеки**: Полки работают как теги/категории, а книги — как сами заметки. Толщина корешка динамически зависит от объёма текста.
-  **Атмосферное чтение**: 3D-анимация снятия книги с полки, раскрытия 
- **Механика подписи**: Превращайте черновики в «настоящие книги». Подписанная книга получает титульную страницу и становится read-only
- **Мини-разметка**: Пишите текст одним блоком, а в режиме чтения он автоматически форматируется и разбивается на страницы.
- **Локальное хранение**: Данные сохраняются в `localStorage` с автосохранением (debounce 500 мс).
- **Портативность**: Экспорт/импорт всей библиотеки в `.json` и экспорт отдельных книг в `.md` (с YAML front-matter).

## ⌨️ Горячие клавиши

| Клавиши | Действие |
| :--- | :--- |
| `Esc` | Закрыть книгу / модалку (или очистить поиск) |
| `←` / `→` | Листать страницы разворота (в режиме «Читать») |
| `Ctrl+S` / `Cmd+S` | Сохранить немедленно |
| `Tab` (в тексте) | Вставить два пробела (удобно для списков) |

## Шпаргалка по мини-разметке

| Синтаксис | Результат |
| :--- | :--- |
| `# Заголовок` | Заголовок (H1, H2, H3) |
| `**жирный**` | **Жирный текст** |
| `*курсив*` | *Курсив* |
| `` `код` `` | `Инлайн-код` |
| `~~зачёркнутый~~` | ~~Зачёркнутый~~ |
| `- пункт` | Маркированный список |
| `1. пункт` | Нумерованный список |
| `> цитата` | Цитата |
| `---` | Горизонтальный разделитель |
| `[текст](url)` | Ссылка |

## Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `index.html` | Разметка: зал, оверлей книги, модалки |
| `style.css` | Весь стиль, палитра и CSS-анимации |
| `script.js` | Логика: данные, пагинация, рендер, хоткеи |

## Локальный запуск
Бэкенд не нужен. Достаточно скачать и распаковать репозиторий, открыть `index.html` в браузере.
